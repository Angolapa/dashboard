# Templates (Plantillas)

Layouts de página que definen la estructura pero sin contenido real.

## Ejemplos:

- MainLayout (Header + Content + Footer)
- DashboardLayout (Sidebar + MainContent)
- AuthLayout (CenteredForm + Background)
- TwoColumnLayout

## Características:

- Definen la estructura de las páginas
- Organizan organismos en la página
- No contienen datos reales
- Son reutilizables para múltiples páginas
