# Rutas Públicas

Esta carpeta contiene todas las rutas accesibles sin autenticación.

## Rutas incluidas:

- `/` - Página de inicio/landing
- `/login` - (agregar) Inicio de sesión
- `/register` - (agregar) Registro de usuarios
- `/about` - (agregar) Acerca de

## Características:

- No requieren autenticación
- Accesibles para todos los visitantes
- Redirigen al dashboard si el usuario ya está autenticado
- Layout limpio sin navegación interna
