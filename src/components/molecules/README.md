# Molecules (Moléculas)

Combinaciones simples de átomos que funcionan juntas como una unidad.

## Ejemplos:

- SearchBar (Input + Button)
- FormField (Label + Input + ErrorMessage)
- Card (Image + Title + Description)
- MenuItem (Icon + Text)

## Características:

- Combinan 2-5 átomos
- Tienen un propósito específico
- Son reutilizables en diferentes contextos
- Pueden tener lógica simple
