# Atoms (Átomos)

Componentes básicos e indivisibles de la interfaz. No pueden dividirse más sin perder su función.

## Ejemplos:

- Button
- Input
- Label
- Icon
- Text
- Image

## Características:

- Son los componentes más pequeños
- No contienen otros componentes (o muy raramente)
- Son altamente reutilizables
- No tienen lógica de negocio
