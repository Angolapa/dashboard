# Organisms (Organismos)

Componentes complejos formados por grupos de moléculas y/o átomos.

## Ejemplos:
- Header (Logo + Navigation + SearchBar + UserMenu)
- Footer (Links + SocialMedia + Newsletter)
- Sidebar (Navigation + UserProfile)
- ProductGrid (múltiples Cards)

## Características:
- Forman secciones completas de la interfaz
- Pueden contener lógica de negocio
- Son específicos de la aplicación
- Combinan múltiples moléculas y átomos
